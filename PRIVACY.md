# Kebijakan Privasi Rampage Rex

Berlaku sejak: 20 November 2026

Rampage Rex adalah game offline buatan Cendy Saputra. Kebijakan ini berlaku untuk aplikasi Android, Windows, macOS, dan versi web.

## Data yang dikumpulkan

**Tidak ada.** Rampage Rex tidak meminta akun, tidak memuat iklan, tidak memakai analitik atau pelacak, dan tidak mengirim data apa pun ke server kami atau pihak ketiga.

## Data yang disimpan di perangkat

Game menyimpan hal berikut **hanya di perangkat kamu**:

- progres distrik, bintang, dan skor
- statistik, pencapaian, dan misi harian
- skin yang terbuka
- pengaturan (suara, getaran, bahasa, grafik)

Data ini tidak pernah keluar dari perangkat. Kamu bisa menghapusnya kapan saja:

- lewat tombol hapus progres di Pengaturan,
- dengan menghapus data aplikasi,
- atau dengan mencopot pemasangan game.

## Izin perangkat

- **Getar** (Android): untuk efek getar saat Rex menyerang atau terkena serangan. Bisa dimatikan di Pengaturan.

Game tidak meminta akses ke kamera, mikrofon, lokasi, kontak, atau file kamu.

## Versi web

Situs web disajikan oleh penyedia hosting (Vercel). Seperti semua server web, penyedia hosting dapat mencatat data teknis standar seperti alamat IP dan jenis browser untuk keamanan dan operasional. Kami tidak memakai data itu untuk melacak pemain.

## Anak-anak

Game ini tidak mengumpulkan data pribadi siapa pun, termasuk anak-anak.

## Perubahan kebijakan

Jika kebijakan ini berubah, versi terbaru akan dimuat di halaman ini beserta tanggal berlakunya.

## Kontak

Pertanyaan tentang privasi dapat dikirim lewat halaman Issues di repositori GitHub Rampage Rex.

# Rampage Rex Privacy Policy

Effective: 20 November 2026

Rampage Rex is an offline game made by Cendy Saputra. This policy covers the Android, Windows, macOS and web versions.

## Data we collect

**None.** Rampage Rex has no accounts, no ads, no analytics or trackers, and sends no data to us or to any third party.

## Data stored on your device

The game stores the following **only on your device**:

- district progress, stars and scores
- statistics, achievements and daily missions
- unlocked skins
- settings (sound, vibration, language, graphics)

This data never leaves your device. You can delete it at any time:

- with the reset progress button in Settings,
- by clearing the app's data,
- or by uninstalling the game.

## Device permissions

- **Vibration** (Android): for haptic feedback when Rex attacks or is hit. It can be turned off in Settings.

The game does not request access to your camera, microphone, location, contacts or files.

## Web version

The website is served by a hosting provider (Vercel). Like any web server, the host may log standard technical data such as IP address and browser type for security and operations. We do not use that data to track players.

## Children

The game collects no personal data from anyone, including children.

## Changes

If this policy changes, the latest version will be posted on this page with its effective date.

## Contact

Privacy questions can be sent through the Issues page of the Rampage Rex GitHub repository.
