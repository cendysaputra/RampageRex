# 12.3 Memasang animasi Rex

Paket ini memakai Rex merah yang menghadap ke kanan. WebP adalah aset gim. GIF memperlihatkan urutan dan tempo yang disarankan. GIF tumbang berulang untuk keperluan pratinjau. Di dalam gim, mainkan sekali dan tahan pose terakhir.

## 1. Daftarkan kedua atlas

Salin isi folder `assets` dari paket ke folder `assets` proyek dengan struktur yang sama. Gabungkan isi tiga objek dari `manifest-fragment.json` ke objek bernama sama di `assets/manifest.json`:

- `assets` mendaftarkan ukuran gambar agar `Art.preload()` memuat kedua WebP.
- `rexAnimations.atlases` memberi `Art.prepareRexFrames()` lokasi setiap frame. Masing-masing berupa `[x, y, lebar, tinggi, pivotX, pivotY]` dalam piksel.
- `rexAnimations.clips` berisi urutan frame dan durasi `frameMs`. Pertahankan klip lama serta nilai `rexAnimations.width` yang sudah ada.

Ikuti konvensi proyek: nama entri di objek `assets` berakhiran `.png`, nilai `path` atlas tanpa ekstensi, dan berkas fisik berakhiran `.webp`. Kedua atlas disusun dua kolom dalam urutan baca kiri ke kanan. Pivot sudah menyimpan ketinggian lompatan. Gambar frame di posisi Rex biasa agar tinggi lompatan sesuai dengan pratinjau.

## 2. Pilih frame di rex-animation.js

Tambahkan cabang berikut di awal `rexPose(rex, animation)`, sebelum pemilihan pose serangan. Gunakan jalur pemutaran tersendiri karena urutan waktu serangan biasa di gim dirancang untuk empat pose. `rex.motionAge` memakai detik simulasi.

```js
if (rex.motion === 'jump' || rex.motion === 'knockdown') {
  const clip = animation.clips[rex.motion];
  let remaining = rex.motionAge * 1000;
  let index = 0;
  while (index < clip.frames.length - 1 && remaining >= clip.frameMs[index]) {
    remaining -= clip.frameMs[index];
    index++;
  }
  const path = rexFramePath(clip.atlas, clip.frames[index]);
  return { from: path, to: path, mix: 0 };
}
```

## 3. Picu gerakan di world.js dan main.js

Inisialisasi `motion: null` dan `motionAge: 0` di objek Rex. Ambil durasi dari jumlah `frameMs` dalam manifest dan bagi 1000 untuk mendapatkan detik. Teruskan kedua durasi ke `World` saat membuat level. Rekomendasi awal adalah 705 ms untuk lompat dan 930 ms untuk tumbang.

**Lompat.** Tambahkan `Space: 'jump'` pada pemetaan tombol di `main.js`. Pakai peristiwa tekan pertama atau deteksi transisi tombol agar menahan spasi hanya memicu satu lompatan. Dalam `World.update(dt, input)`, mulai `motion = 'jump'` dan nolkan `motionAge` saat Rex masih hidup, bebas stun, dan tidak sedang menyerang atau melompat. Majukan penghitung dengan `dt`. Setelah durasi klip habis, kembalikan `motion` ke `null` agar pose idle atau jalan mengambil alih. Selama lompat, cegah antrean serangan baru agar serangan tersembunyi tidak menghasilkan damage. Tombol sentuh dapat mengirim aksi `jump` melalui jalur input yang sama.

**Tumbang.** Saat HP mencapai nol, ganti transisi langsung ke `status = 'lost'` dengan memulai `motion = 'knockdown'` satu kali. Nolkan penghitung, hentikan gerak dan bersihkan serangan aktif serta antreannya. Pada awal update berikutnya, jika Rex sedang tumbang, majukan hanya `motionAge` lalu keluar dari update. Pertahankan status dunia `playing` selama klip berjalan karena `main.js` berhenti memperbarui simulasi dan membuka panel hasil saat status berubah. Set `lost` setelah 930 ms. Pose keenam mendapat 390 ms di layar sebelum panel hasil muncul.

## 4. Cek di gim

- Tekan lalu tahan spasi. Rex harus jongkok, lepas landas, mengaum di puncak, mendarat, lalu kembali ke pose awal dalam satu siklus.
- Coba saat Rex menghadap kiri. Renderer yang ada mencerminkan pose menurut `dir`.
- Turunkan HP sampai nol saat Rex berdiri dan saat melompat. Keduanya harus berakhir dengan Rex menempel tanah dan panel kalah muncul sesudah pose pingsan.
- Atlas ini memberi lompatan visual. Untuk fitur melompati proyektil, gunakan ketinggian yang sesuai pada perhitungan tabrakan di `world.js` juga.
